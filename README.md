## 🤝 Como contribuir com os projetos

Os projetos são mantidos no tempo livre. Há duas formas de ajudar:

**Com código**
1. Faça um fork do repositório
2. Crie uma branch (`git checkout -b minha-melhoria`)
3. Faça o commit e abra um Pull Request
4. Issues com bugs e sugestões também são bem-vindas
